# rosbag-rerun

Read ROS bags without installing ROS, and use the message streams for Rerun
visualization. The Python reader is available now; C++ and Rust are planned.

| Language | Status | Guide |
| --- | --- | --- |
| Python | Reader, synchronization, playback, and Rerun viewer | [Python README](python/README.md) |
| C++ | Future work | [C++ README](cpp/README.md) |
| Rust | Future work | [Rust README](rust/README.md) |

Start with the [Python guide](python/README.md) for installation, examples,
API usage, and data layout.

Shared Rerun [blueprints and recordings](rerun/README.md) live under `rerun/`
so future C++ and Rust implementations can use the same files.
